# Evalnor Talent

Private Evalnor product for HR, recruiting, staffing and placement agencies.

## Architecture
- Domain: recruiting and HR business rules
- Adapters: replaceable integrations
- Presentation: responsive workflow UI
- Platform integration: Evalnor Core + Evalnor Control Center through contracts/APIs

## Product principles
Commercializable by design; no personal data hard-coded; FR/EN/ES; role-based access; auditability; secure validation; import/export; migrations; clean uninstall; API-first portability beyond WordPress.

## Initial domain
Candidates, employers, jobs, pipelines, CV/documents, interviews, placements, commissions, tasks and automations.
